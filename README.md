### Frontend Setup

The frontend is built with **Vite, React, and TypeScript**.

1. Clone the repository.

2. Create the .env file using .env.example.

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

The frontend will be available at the URL shown by Vite, usually `http://localhost:5173`.
